# World With Barrier — Minecraft 1.21.1

Датапак расширяет границу мира (`worldborder`) по мере получения достижений. Ниже описана сборка **1.2.4 для мультиплеера**:

`WWB 1.21.1 1.2.4/world with barrier 1.21.1 (multiplayer) 1.2.4`

## Как работает датапак

1. При загрузке мира датапак создаёт служебную цель scoreboard и проверяет игроков каждый игровой тик.
2. При первой настройке команда `@p` выбирает игрока, по которому задаётся центр границы. Все игроки, находящиеся в мире в этот момент, телепортируются к нему. Начальный размер границы — **20 блоков**.
3. Датапак проверяет достижения игроков. Для каждого достижения, прописанного в функции, используется числовой тег: он отмечает, что это достижение уже обработано для данного игрока.
4. Когда игрок получает такое достижение, датапак добавляет к размеру мировой границы заданное для него число блоков. Прибавки отличаются: большинство небольшие, за отдельные сложные достижения выдаются большие.
5. Каждая прибавка проходит через проверку лимита. Если новый размер достигнет или превысит **6000 блоков**, граница устанавливается ровно на 6000 и дальнейшее расширение прекращается. Проверка также выполняется каждый тик, поэтому уже достигнутая граница не продолжит расти.

Размер `worldborder` в Minecraft — это ширина границы **от края до края**, а не радиус. Поэтому максимальный размер 6000 означает примерно по 3000 блоков от центра в каждую сторону.

Граница общая для мира: это не отдельная граница для каждого игрока. В мультиплеере датапак отмечает обработанные достижения тегами игроков и проверяет наличие ближайшего игрока с таким тегом, чтобы не выдавать одну награду повторно. Поскольку используется проверка ближайшего игрока, если игроки разойдутся далеко друг от друга, одно и то же достижение может в отдельных случаях увеличить общую границу больше одного раза. Общий лимит 6000 при этом сохраняется.

Датапак меняет именно границу мира — он не строит стену из блоков и не выдаёт предметы.

## Какие достижения учитываются

В сборке прописаны проверки достижений Minecraft и перечисленных ниже модов. Число показывает, сколько разных достижений этого пространства имён сейчас настроено на увеличение границы.

| Игра или мод | Пространство имён достижений | Достижений с наградой |
| --- | --- | ---: |
| Minecraft (ванильные достижения) | `minecraft` | 121 |
| Create | `create` | 90 |
| Create: Connected | `create_connected` | 8 |
| Create: Aeronautics | `aeronautics` | 9 |
| Create: Simulated | `simulated` | 29 |
| Farmer's Delight | `farmersdelight` | 20 |
| More Delight | `moredelight` | 8 |

Для игры с модовыми достижениями **рекомендуется как минимум установить Create**. Датапак также содержит проверки достижений остальных модов из таблицы. Модовые награды сработают только при наличии соответствующих достижений; если мода нет или его версия использует другие идентификаторы, награды не начислятся, а в журнале могут появляться сообщения о неизвестных достижениях. Датапак не добавляет эти моды и не заменяет их.

## Установка

1. Скопируйте папку сборки в папку `datapacks` нужного мира. На сервере это `<папка_мира>/datapacks`.
2. Запустите или перезагрузите мир командой `/reload`.
3. Убедитесь, что датапак включён командой `/datapack list`.

Сборка рассчитана на **Minecraft Java Edition 1.21.1**. Совместимость с конкретным загрузчиком модов зависит от используемой сборки игры и версий самих модов.
